# Keep Mobile independent from Admin application infrastructure

Build `apps/mobile` as an independent standard Vue application inside the existing pnpm and Turbo workspace. Do not depend on the Vben locale, Vite, TypeScript, layout, store, or UI infrastructure created primarily for Admin. Reuse `@vben/request` for its UI-independent RequestClient and authentication interceptors, `@vben/preferences` for namespaced runtime settings and persistence, and `@vben/utils` for input normalization because concrete Mobile use cases exist for them. Mobile keeps its own static `vue-i18n`, Vant, and Day.js locale integration; language changes explicitly call `updatePreferences({ app: { locale } })` and then `loadLocaleMessages(locale)`. Do not add the Admin preferences UI, layouts, dynamic locales, adapters, or unused configuration merely to resemble Admin.
