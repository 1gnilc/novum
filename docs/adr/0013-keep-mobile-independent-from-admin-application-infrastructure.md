# Keep Mobile independent from Admin application infrastructure

Build `apps/mobile` as an independent standard Vue application inside the existing pnpm and Turbo workspace. Do not depend on the Vben locale, Vite, TypeScript, preferences, layout, store, or UI infrastructure created primarily for Admin. Reuse `@vben/request` for its UI-independent RequestClient and authentication interceptors, and `@vben/utils` for locale storage and input normalization, because concrete Mobile use cases exist for both. Import cache utilities through `@vben/utils/cache` and general helpers through `@vben/utils/shared`, so Mobile and the shared request package do not depend on the root aggregation of router helpers. Keep the root export compatible for existing consumers. Mobile must not import Admin adapters into these shared packages or add unused configuration merely to resemble Admin.
