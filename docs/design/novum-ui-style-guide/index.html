01

移动端概览

三档均为竖屏触控环境，没有桌面端断点。

小屏设备 360 × 800 · DPR 3 65 / 74 页面记录可见
标准手机 430 × 932 · DPR 3 59 / 74 页面记录可见
大屏 / 平板 768 × 1024 · DPR 2 71 / 74 页面记录可见

视觉特征 深青画布、蓝灰表面、橙色操作、紫色选中态与低阴影层级。

可信度 “实测值”来自运行时样式；“推测值”仅用于归纳 spacing scale。
